## 긴 이미지 분할 + 대체텍스트 처리 예시 (b0b69dc...jpg)

원본 홍보 이미지(720×7700, 모든 글자가 이미지에 그려져 있음)를 **실제로 잘라**
HTML에서 다시 이어 붙인 예시. 화면에는 원본과 똑같이 보이되, 각 조각마다
그 안의 글자 내용을 대체텍스트(alt)로 넣어 스크린리더가 읽을 수 있게 처리.

- `index.html` — 잘린 12조각을 세로로 이어 붙인 페이지 (조각마다 alt 처리)
- `sections/` — 원본을 의미 단위 12조각으로 분할한 이미지

### 처리 포인트
- 조각 사이 틈 없이 스택(`img{display:block;width:100%}`) → 원본 재현
- 각 조각 alt = 그 조각의 글자 내용 (KWCAG #1 / WCAG 1.1.1)
- 이미지로 박힌 '스마트 예약' 버튼 위에 보이지 않는 실제 링크를 겹쳐 키보드 조작 가능
- 본문 바로가기 스킵 링크, lang="ko", 축소·확대 허용

브라우저에서 `index.html` 열기 (루트에서 `python3 serve.py` 후 접속).
※ alt는 차선책이며, WCAG 1.4.5는 가능하면 글자를 실제 텍스트로 제공할 것을 권장.
