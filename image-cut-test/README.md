## WCAG 재구성 예시 (b0b69dc...jpg)

긴 홍보 이미지(720×7700, 모든 글자가 이미지에 그려져 있어 스크린리더가 읽지 못함)를
KWCAG 2.2 / WCAG 2.2 AA 기준으로 처리한 예시.

- `wcag-example.html` — 재구성된 접근성 안내 페이지 + 조각별 처리 설명
- `sections/` — 원본을 의미 단위 12조각으로 분할한 이미지

### 처리 원칙
1. 이미지 속 글자는 모두 실제 HTML 텍스트로 복원 (1.1.1 / 1.4.5)
2. 사진은 정보전달(의미 있는 alt) / 장식(alt="")으로 구분
3. 제목 계층·정의목록·표로 구조화, 흰 배경 대비 4.5:1 이상으로 재배색
4. 스킵 링크·landmark·또렷한 focus 표시·축소확대 허용

브라우저에서 `wcag-example.html`을 열어 확인. (저장소 루트에서 `python3 serve.py` 후 접속 가능)
